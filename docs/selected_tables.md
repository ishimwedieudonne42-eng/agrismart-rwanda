Initial Dashboard Questions

1. How does the reported yield of a selected crop differ between districts?
2. How did national production change between Season B 2023, 2024 and 2025?
3. Which crops account for the largest reported production?
4. How do reported agricultural practices vary across districts?
5. Which districts report higher proportions of plots in the different erosion categories?

Data Validation Requirements

Before publishing dashboard results:

- Confirm units and definitions for each table.
- Check that district names and crop categories are consistent.
- Distinguish missing values from genuine zeros.
- Verify the reference period and any applicable sampling or estimation notes.
- Avoid adding district percentages together when their denominators differ.
- Do not interpret descriptive associations as proof of causation.

## Machine Learning Decision

Machine learning will be considered only after identifying suitable observations, predictors, and target variables. The published summary tables will initially support descriptive analysis rather than farm-level prediction.
