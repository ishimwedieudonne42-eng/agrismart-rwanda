AgriSmart Rwanda — Data Directory

This directory contains documentation and, where permitted, datasets used by the AgriSmart Rwanda project.

Directory Organization

- raw — Original datasets, preserved without modification. Do not upload restricted or confidential data.
- processed — Cleaned datasets prepared for analysis, subject to applicable data-use conditions.
- external — Additional datasets from verified sources, with source information recorded.

Data Management Rules

1. Record the source and reference period of every dataset.
2. Read the dataset documentation before analyzing its contents.
3. Check access permissions and licensing before downloading, publishing, or redistributing data.
4. Keep original data unchanged and perform cleaning on separate copies.
5. Never upload passwords, API keys, personal information, or restricted microdata to a public repository.
6. Document missing values, data transformations, assumptions, and limitations.
7. Do not invent statistics or present unvalidated predictions as facts.
